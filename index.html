    How this version works

    Guess five different digits, including a possible leading zero. You may enter any valid five-digit code. The r count means the correct digit in the correct position. The s count means shared digits, including every r.

    The answer is selected dynamically from codes consistent with all earlier replies. Higher levels favor replies estimated to be harder; lower levels favor easier replies. Classic (0) has the same reply probabilities as a uniformly random fixed secret.

    The number on each level is its difficulty coefficient (λ). Choose it before your first valid guess; it stays locked for the round. Only 5r5s wins, even if earlier clues already identify one possible answer.

    “Reveal an answer” ends the round and shows one code that fits the full history. New game or refresh clears the current guesses. No statistics, saved games, accounts or tracking.

    Runs on your device. No game history is saved. Refresh to start fresh.
